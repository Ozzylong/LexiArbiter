# LexiArbiter

針對台灣司法判決進行 multi-task learning 標註資料製作的 Windows 桌面工具。
讀取司法院 open data JSON 檔，用螢光筆方式為每一段文字同時套上多個分類標籤，最後一鍵匯出成模型訓練可直接用的 `.txt`（例如 `<P>大前提,非第一人稱|...</P>`）。



## 主要特色

- **多群組標籤**：同一段文字可同時帶有不同群組的標籤（例如「論證類別 = 大前提」+ 「人稱 = 非第一人稱」），符合 MTL 訓練資料結構。
- **三種觸發方式**：上方工具列按鈕、鍵盤快速鍵、滑鼠右鍵選單，挑你順手的那一種。
- **接力標註友善**：除了最終匯出的 `.txt`，可另存為專屬 `.lexa` 進度檔（含完整原文 + 已標註資料），方便交給另一位標註者接著做。
- **標註模式可換**：標籤項目、顏色、快速鍵、輸出格式由 `configs/annotation_modes/*.json` 描述，不必改程式碼也能新增/切換模式。

## 下載與安裝

1. 到 [GitHub Releases](https://github.com/Ozzylong/LexiArbiter/releases) 下載最新版的 `LexiArbiter-vX.X.X-win64.zip`。
2. 解壓縮到任意位置（建議放在自己有寫入權限的資料夾，例如桌面或 `D:\Tools\`）。
3. 進入解壓出來的資料夾，雙擊 `LexiArbiter.exe` 即可啟動。

**系統需求**：Windows 10 / 11 (64-bit)。不需要另外安裝 Python。

> 解壓後請保持資料夾結構完整 —— `LexiArbiter.exe`、`_internal/`、`configs/`、`assets/` 要放在一起，不要只把 exe 抽出來。

## 第一次使用

啟動後會看到三大區域：

- **上方工具列**：開啟檔案／儲存進度／匯出 `.txt`，以及目前標註模式提供的全部標籤按鈕（每個顏色就是一個標籤）。
- **中央文字編輯區**：載入的判決文字，已標註的段落會用該標籤的顏色塗起來。
- **右側檔案清單**：與目前開啟檔案放在「同一個資料夾」的所有判決，雙擊可快速切換。
- **下方狀態列**：顯示目前檔案路徑、是否有未儲存的修改、目前的標註模式。

### 標註一份判決的完整流程

1. **開啟檔案**：上方工具列「開啟檔案」按鈕，或選單 **檔案 → 開啟檔案…**（`Ctrl+O`），選一份司法院 open data 的 `.json`。
   - 若是要繼續別人交接的工作，改開 `.lexa` 即可，原本標好的內容會一起載回來。

2. **用滑鼠選取要標註的文字**（像反白一樣）。

3. **套用標籤**，三種方式擇一：
   - 點上方工具列對應顏色的按鈕；
   - 按該標籤的鍵盤快速鍵（例如預設 `Ctrl+3` = 大前提）；
   - 在反白的文字上按滑鼠右鍵，從彈出選單挑一個標籤。

4. **同一段可疊加不同群組的標籤**。例如先用 `Ctrl+3` 標成「大前提」，再用 `Ctrl+Shift+2` 補上「非第一人稱」，這段就會帶兩個標籤。

5. **儲存進度**：選單 **檔案 → 儲存標註進度 (.lexa)**（`Ctrl+S`）。標到一半關掉程式，下次開這個 `.lexa` 可以接續。
   - 程式會每 60 秒自動存一份 `*.autosave.<時間戳>.lexa` 在原檔旁邊，當保險用。

6. **匯出模型訓練資料**：全部標完後選單 **檔案 → 匯出模型用 .txt…**（`Ctrl+E`），會輸出每行一個 `<P>標籤,標籤|文字</P>` 的純文字檔。

## 檔案類型

| 副檔名 | 用途 | 由誰產生 |
| --- | --- | --- |
| `.json` | 司法院判決 open data 原始檔，程式只會讀取 `JFULL` 欄位 | 外部資料來源 |
| `.lexa` | LexiArbiter 的進度檔（JSON 格式），內含完整原文 + 已標註資料，適合多人接力 | LexiArbiter「儲存標註進度」 |
| `.txt` | 模型訓練用的最終輸出，每行一個 `<P>標籤,標籤|文字</P>` 段落 | LexiArbiter「匯出模型用 .txt」 |

## 預設標註類別（`legal_mtl` 模式）

| 群組 | 角色 | 類別 | 預設快速鍵 |
| --- | --- | --- | --- |
| 論證類別 | 主任務 (primary) | 程序 / 事實 / 大前提 / 小前提 / 心證其他 / 結論 | `Ctrl+1` ~ `Ctrl+6` |
| 人稱 | 輔助任務 (auxiliary) | 第一人稱 / 非第一人稱 | `Ctrl+Shift+1` / `Ctrl+Shift+2` |

## 鍵盤快速鍵總覽

| 操作 | 預設快速鍵 |
| --- | --- |
| 開啟檔案 | `Ctrl+O` |
| 開啟資料夾 | `Ctrl+Shift+O` |
| 儲存標註進度 (.lexa) | `Ctrl+S` |
| 匯出模型用 .txt | `Ctrl+E` |
| 刪除游標處標註 | `Ctrl+D` |
| 切換到上一個檔案 | `Alt+Up` |
| 切換到下一個檔案 | `Alt+Down` |
| 離開程式 | `Ctrl+Q` |
| 套用標籤 | 見上方「預設標註類別」表格 |

想改成自己順手的鍵位，可編輯 `configs/user_preferences.json` 的 `shortcut_overrides`（見下一節）。

## 自訂標註模式

如果預設的「論證類別 + 人稱」不符需求，可以自己定義一份新的標註模式 —— 完全不需要改程式碼。

**步驟：**

1. 打開程式安裝資料夾裡的 `configs/annotation_modes/`，複製 `legal_mtl.json` 一份，改個檔名（例如 `my_mode.json`）。
2. 用文字編輯器打開新檔，依下方範例修改裡面的群組、標籤、顏色、快速鍵、輸出格式。
3. 存檔後**關掉程式重新啟動**，新模式就會出現在選單 **標註模式** 裡。
4. 從選單切換到新模式即可開始使用。

> 也可以用程式內的 **標註模式 → 開啟模式資料夾** 直接打開該資料夾。

**完整範例：**

```json
{
  "id": "my_mode",
  "name": "我的標註模式",
  "groups": [
    {
      "id": "topic",
      "name": "主題",
      "role": "primary",
      "labels": [
        {"id": "a", "name": "甲", "tag": "甲", "color": "#FFD54F", "shortcut": "Ctrl+1"},
        {"id": "b", "name": "乙", "tag": "乙", "color": "#64B5F6", "shortcut": "Ctrl+2"}
      ]
    }
  ],
  "export": {
    "tag_order": ["topic"],
    "tag_separator": ",",
    "wrapper_open": "<P>",
    "wrapper_close": "</P>",
    "field_separator": "|",
    "include_unannotated": false,
    "require_all_groups": false
  }
}
```

**欄位說明：**

- `id`：模式內部識別碼（英數，獨一無二）；存進 `.lexa` 後也用這個欄位辨識。
- `name`：顯示在選單上的中文名稱。
- `groups[].role`：`primary`（主任務，每段必標）或 `auxiliary`（輔助任務，可選）。
- `labels[].color`：HEX 色碼；填 `null` 表示這個標籤不上色，只在輸出標籤名。
- `labels[].shortcut`：Qt 標準格式，例如 `"Ctrl+1"`、`"Ctrl+Shift+A"`、`"F2"`。
- `export.tag_order`：匯出時標籤的排列順序（依 `group_id`）。
- `export.require_all_groups`：設 `true` 時，未標滿全部群組的段落會在匯出時被略過/警示。

**個人偏好設定**（字型大小、主題、覆寫快速鍵等）放在 `configs/user_preferences.json`，與模式檔分開存放 —— 換模式不會弄丟你的鍵盤習慣。

## 疑難排解

- **改了 `configs/` 裡的檔案後沒看到效果？**
  關掉程式重新啟動，設定檔只會在啟動時讀取一次。

- **程式突然當掉了？**
  程式在 crash 前會嘗試自動緊急存檔到原檔旁邊的 `<原檔名>.crash_backup.lexa`，直接用「開啟檔案」打開它即可救回。
  若當下沒有開檔，則會寫到 log 資料夾下的 `emergency_<時間戳>.crash_backup.lexa`。

- **想找之前的自動存檔？**
  原檔旁邊會有 `<原檔名>.autosave.<時間戳>.lexa`，每 60 秒一份。

- **想看詳細執行記錄（log）？**
  選單 **說明 → 開啟 log 資料夾** 會直接幫你打開 log 所在位置。回報問題時把 `lexiarbiter.log` 一起附上，會比較好排查。

- **打開 `.lexa` 後跳出「要不要切換標註模式」？**
  這是正常的 —— 該 `.lexa` 當初是用另一個標註模式存的。確認後切過去就會正常顯示。

- **回報 bug 時要附什麼資訊？**
  選單 **說明 → 複製診斷資訊** 會把版本、log 路徑、平台資訊複製到剪貼簿，貼上即可。
